# Examples

| Directory | Profile | Shows |
|---|---|---|
| `minimal-l0/` | L0 | the smallest valid DSX: mandatory frame + time, two sampled aircraft |
| `show-l1/` | L1 | *(to be written)* segment trajectories, device binding, geofence, RTH |
| `pyro-l2/` | L2 | *(to be written)* payloads, termination, provenance signature |
| `rotation-l2/` | L2 | enumerated rotation: 42 min from 6 aircraft flying 450 s sorties (§10.1–§10.7) |
| `continuous-l2/` | L2 | **indefinite** show: `wave_cycle`, steady-state closure, drain plan (§10.8) |

Each example directory is the **unzipped content** of a `.dsx` file. To build one:

```sh
cd minimal-l0 && zip -r ../minimal-l0.dsx .
```

Both L2 examples carry their device profile (`devices/example-aircraft.dsxp`)
inside the example directory, because a `.dsx` that references a profile it
does not carry is invalid (§2).

Every example is a **complete archive**: each referenced trajectory, light,
geometry and audio resource is carried inside it, because §2.1 makes a show
that references a resource it does not carry invalid. The payload resources of
`rotation-l2/` and `continuous-l2/` are generated by
`tools/build_examples.py` — driven by the manifest itself, so the geometry and
the choreography cannot drift apart — and validated against
`schema/resource.schema.json`.

Both L2 examples carry a **real** `content_hash` and a **real** ed25519
signature, produced by `tools/dsx_seal.py` with the publicly derived demo key.
Editing any byte of either archive breaks both, which is the point:

```
python3 tools/dsx_seal.py verify examples/rotation-l2
```

The demo key is derived from a seed printed in `tools/dsx_seal.py`. It proves
the mechanism works; it guarantees nothing about the show, and
`conformance/check_archive.py` prints a WARN whenever it sees it. Re-seal after
editing an example (`tools/dsx_seal.py seal <dir>`), or the archive checks
fail.

Note that even the minimal example must declare `alt_ref`, `handedness` and
`bearing_deg`. That is intentional: those three fields are the ones whose
absence causes conversion accidents, so there is no profile in which they are
optional.
