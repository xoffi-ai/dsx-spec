**Why both.** CC BY is the licence documentation culture expects. But it
contains no patent grant, and manufacturers' legal departments will not
authorise an implementation without one. Apache-2.0 §3 supplies that grant:
every contributor licenses their necessary patent claims, royalty-free, to
every implementer. Offering the text under Apache-2.0 as well is what turns
"patent-safe" from a promise into a term.

An earlier draft of this file named the Open Web Foundation Agreement (OWFa)
as the patent mechanism. That was wrong: OWFa is an agreement that must be
executed by each party, not a licence that attaches to a repository, so listing
it here would have bound no one while appearing to. It was removed before
publication rather than defended.
